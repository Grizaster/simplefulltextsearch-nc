# Security Policy

## Supported Versions

Only the latest release of SimpleFullTextFileSearch is supported. Please
update before reporting — many issues are already fixed in newer versions.

## Reporting a Vulnerability

**⚠️ Do _not_ report security vulnerabilities through public GitHub issues.**

Instead, use [GitHub private vulnerability reporting](https://github.com/Grizaster/simplefulltextsearch-nc/security/advisories/new)
(Security tab → "Report a vulnerability"). Your report stays confidential
until a fix is published.

Please include:

- what the issue is and its impact
- steps to reproduce (or a proof of concept)
- affected app / Nextcloud / PHP versions

This is a hobby project maintained in spare time — expect a best-effort
response, not an SLA. Reports about the app's own code are in scope;
vulnerabilities in Nextcloud core itself belong to the
[Nextcloud security process](https://hackerone.com/nextcloud).
